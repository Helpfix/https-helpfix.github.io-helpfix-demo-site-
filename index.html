Sobre esta demonstração

Do código ao link em poucos passos.

Este modelo foi preparado para testar a publicação de um site no GitHub Pages. Você pode abrir o arquivo diretamente no navegador, editar os textos e depois enviar para o seu repositório.

  • Arquivo único chamado index.html
  • Estilo CSS incluído na própria página
  • Navegação por seções com âncoras
  • Pronto para uma primeira publicação de teste

Gostou do resultado?

Este é apenas um exemplo. O próximo passo é personalizar uma versão para cada cliente, com identidade visual, informações e conteúdo reais.
